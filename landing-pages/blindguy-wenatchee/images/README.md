# Landing page images

Drop your photos into this folder using the **exact filenames** below. The page
is already wired to these names. Until a file exists, that slot gracefully shows
the branded gradient (no broken-image icon).

Recommended: ~800×600px (4:3), JPG or WebP, optimized for web (under ~300 KB each).
